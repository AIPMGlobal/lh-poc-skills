# LH 발표 디자인

고정하는 것은 화면 비율, 색, 글꼴, 바깥 여백, 표지 구성, 제목의 위계, 하단 줄이다. 장 구성과 이야기는 [대화와 구성 제안](dialogue-workflow.md)에서 합의한 흐름을 따르고, 배치는 [장표의 증거 배치](executive-slide-design.md)에서 근거에 맞게 고른다.

## 색과 글꼴의 근거

색은 LH가 쓰는 자료에서 직접 가져왔다. 임의로 고른 색이 아니므로 바꾸지 않는다.

| 쓰임 | 값 | 가져온 곳 |
|---|---|---|
| 강조, 구분 라벨 | `#005DA4` | LH 슬로건(희망을 위한 LH의 약속, Life with Hope)의 파랑 |
| 큰 제목 | `#0B3A8A` | LH 로고의 남색 |
| 제목 아래 띠 | `#0080C0` → `#3CBFFF` | 권장양식 「표지가 있는 보고서(푸른색)」의 제목 띠 |
| 초록 | `#71BF44` | 슬로건의 초록 |
| 주황 | `#F36F21` | 슬로건의 주황 |
| 빨강 | `#E51E2C` | 권장양식(붉은색)의 띠 색. 위험과 문제에만 |
| 보조 글자 | `#636466` | 슬로건의 회색 |
| 본문 / 구분선 / 옅은 바탕 | `#1F2937` / `#D5DEE8` / `#EEF5FB` | 위 색에 맞춰 고른 값 |

한 장에서 강조색은 파랑 하나를 기본으로 한다. 도식에서는 역할 색(코드 파랑, AI 초록, 사람 주황)을 쓴다. 그 밖의 장에서 초록, 주황, 빨강을 장식으로 쓰지 않는다. 색만으로 뜻을 전하지 않고 글자나 범례를 함께 둔다.

글꼴은 **맑은 고딕**이다. LH 서식 기준이 참고 글꼴로 허용하고, LH 업무용 PC에 모두 설치되어 있어 발표장 PC에서 글꼴이 바뀌지 않는다. 휴먼명조와 HY헤드라인M은 한글(HWP) 보고서용이므로 PPT에는 쓰지 않는다.

## 공통 값

`assets/theme.json`을 쓴다. 기준 화면은 1280×720, 실제 PPT는 13.333333×7.5인치다. PptxGenJS에서는 좌표를 96으로 나누고 글자 크기에 0.75를 곱한다. 40px를 40pt로 넣지 않는다.

| 요소 | 기준 |
|---|---|
| 바탕 | 흰색 |
| 좌우 여백 | 64px |
| 구분 라벨 | x64, y30, 18px, 파랑 굵게. 그 장의 역할을 짧게(핵심 요약, 기존 업무의 문제) |
| 큰 제목 | x64, y66, 폭 1036, 40px, 남색 굵게, 한 줄. 오른쪽 로고와 겹치지 않게 26자 안팎 |
| 제목 아래 띠 | y138, 높이 5px, `assets/lh-bar-blue.png` |
| LH 로고 | 오른쪽 위, 높이 약 65px, `assets/lh-logo.png` |
| 내용 영역 | y172부터 y648 안쪽 |
| 본문 | □ 28px, ㅇ 25px, - 22px, * 20px |
| 하단 왼쪽 | 출처 줄 15px 회색. 자료 이름, 기준일, 수치의 성격을 한 번에 |
| 하단 오른쪽 | 발표 부서 이름과 쪽 번호 15px |

구분 라벨은 번호 붙은 고정 목차가 아니다. 합의한 장 구성에서 그 장이 맡은 역할을 적는다. 과정 이름, 교육 기관 이름, 파일 이름, 양식의 출처는 화면과 발표자 노트 어디에도 남기지 않는다.

## 표지와 닫는 장

표지는 LH 권장양식 「표지가 있는 보고서」의 구성을 16:9로 옮긴 것이다. 왼쪽 위에 슬로건(`assets/lh-slogan.png`), 가운데에 두 줄 띠 사이의 제목, 그 아래 현재 위치, 날짜, 소속을 둔다. 제목은 Agent 이름보다 업무 변화의 방향을 말한다. 현재 위치는 `가상 데이터 500건 시험 단계`처럼 사실대로 적는다. 표지에는 로고를 따로 넣지 않는다. 슬로건에 LH가 들어 있다.

닫는 장(`kit.closingSlide`)은 표지와 같은 두 줄 띠 사이에 한 문장 선언을 두고, 아래에 앞 장에서 이미 보여 준 근거 세 가지를 짧게 적는다.

목차 장은 본문이 13장을 넘는 긴 발표에만 넣는다. 짧은 발표에서는 표지 다음에 바로 핵심 요약이 온다.

## 개조식 본문

LH 서식 기준의 색인 순서를 따른다.

```
□ 큰 항목 (굵게, 남색)
   ㅇ 설명
      - 세부 내용
      * 참고 (회색)
```

가운뎃점은 보고서를 어지럽게 한다는 이유로 LH 기준이 쓰지 않도록 한다. 나열은 쉼표, 대등한 두 낱말은 "와/과"로 쓴다. 참고 표시는 ※ 가 아니라 * 다. 한 장에 □ 는 세 개 안팎, 전체 줄 수는 여덟 줄 안팎이 읽기 좋다. 한 항목은 한 줄에 들어가게 쓴다. 넘치면 글자를 줄이기 전에 문장을 줄이거나 장을 나눈다.

모든 장을 개조식으로 채우지 않는다. 핵심 요약은 한 줄 전후 대비(`kit.headline`), 업무 변화는 도식, 시연은 실제 화면, 대조는 표가 맞다.

그림자, 그러데이션 배경, 장식 아이콘, 두꺼운 테두리, 같은 크기의 카드 반복을 기본으로 쓰지 않는다. LH 기준이 과도한 꾸미기를 피하라고 한다. 글자 크기, 정렬, 여백, 제한된 색으로 위계를 만든다.

## 편집할 수 있게 만든다

수치 그래프는 PPT 기본 차트로 만든다. 데이터 편집에서 숫자를 바꾸면 그래프가 바뀌어야 한다. 막대 축은 0에서 시작하고 단위, 기간, 전체 건수를 적는다. 표는 기본 표, 흐름과 역할은 [도식 그리기](diagrams.md)의 도형과 선으로 만든다. 화면 캡처는 그림이어도 되지만 설명 글은 글상자로 둔다.

## 로고와 슬로건

`lh-logo.png`와 `lh-slogan.png`는 LH 보고서 작성 서식에 실린 그림이다. 가로세로 비율, 색, 글자를 바꾸지 않는다. 다른 그림이나 글자와 겹치지 않게 둘레에 여백을 둔다. 어두운 바탕 위에 올리지 않는다.
