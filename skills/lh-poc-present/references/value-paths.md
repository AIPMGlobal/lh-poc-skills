# 과제별 가치 경로 선택

이 표는 경영진의 공식 평가표가 아니라 자료를 해석하기 위한 출발점이다. 한 과제가 여러 경로에 걸칠 수 있으며, 제공 자료에 더 적합한 경로가 있으면 추가한다.

| 경로 | 먼저 확인할 문제 | 조직 가치가 생기는 방식 | 유용한 증거 | 바로 주장할 수 없는 것 |
|---|---|---|---|---|
| 사업 판단·수행 품질 | 정보 취합·기준 불일치·경험 단절이 어떤 판단을 지연시키는가 | 같은 근거로 판단하고 이전 경험을 다음 사업에 사용 | 실제 판단·후속 조치 사례, 근거 정확성, 취합·검토 부담, 재작업 | 조회가 빨라졌다는 이유만으로 납기·수익 개선 |
| 개발·운영 대응력 | 변경 요구와 장애 대응에서 어디가 막히는가 | 요구를 구현·검증하고 정상 운영으로 이어갈 능력 | 동일 유형의 완료 시간, 검토 후 채택, 결함·회귀, 운영 인계 | 코드 생성 속도를 전체 개발 생산성으로 일반화 |
| 공통 자산·확산 | 조직마다 무엇을 다시 만들고 검증하는가 | 지식·구성·절차 재사용으로 다음 적용의 부담 완화 | 재사용한 구성과 수정 범위, 적용 준비 기간, 운영·승인 과정 | 플랫폼 구축·도입 요청을 전체 조직 활용·비용 절감으로 해석 |
| 현업 활용·협업 | 정보가 실제 행동으로 이어지는 데 무엇이 필요한가 | 기존 업무 안에서 이해·검토·협업을 연결 | 실제 반복 사용, 업무 완결 사례, 사용자 관찰, 실패·수정 부담 | 계정·배포 대상 수를 활성 사용자·사업 효과로 해석 |
| 위험 대응·신뢰 | 놓치거나 잘못 판단하면 어떤 업무에 어떤 영향이 생기는가 | 검토 범위를 넓히고 위험을 확인·대응할 준비 강화 | 검토·채택·수정·반려 내역, 탐지와 오탐, 대응 사례, 추적 가능성 | 수집·권고량을 사고 예방액·완전한 안전으로 해석 |
| 입주민·국민 서비스 품질 | 입주민과 민원인이 어떤 불편·오류·대기를 경험하는가 | 실제 문제 해결과 일관된 서비스 제공 | 해결 여부, 재문의·이관, 민원 반응, 접근성·오류 사례 | 응답 속도나 모델 점수를 만족·충성·매출로 바로 전환 |

## 선택 방법

1. 사용자의 실제 문제와 비교하려는 업무 단위를 먼저 찾는다.
2. 후보 가치의 **업무 중요성·작동 원리·현재 증거·다음 결정과의 관련성**을 비교한다. 임의의 점수나 가중 합계를 만들 필요는 없다.
3. 가장 강한 가치를 중심으로 제목과 사례를 고른다. 자료가 약한 가치는 조건부 기대 효과로 남긴다.
4. 주장이 겹치면 같은 효과를 두 번 계산하지 않는다. 같은 가치가 여러 과제에 적용돼도 각자의 역할과 근거가 다르면 그대로 설명한다.

## 정성적 가치도 구체화한다

- **지식의 조직 자산화:** 결과를 저장했다는 사실에 더해 다른 담당자가 다시 사용했는지, 최신성·관리 책임이 있는지 본다.
- **판단의 일관성:** 공통 기준으로 같은 사례를 검토한 결과와 예외 처리, 변경 근거를 본다.
- **전문가 여력 확보:** 줄어든 작업과 새로 생긴 검토 작업을 함께 보고, 확보된 여력을 어디에 쓰는지 확인한다.
- **협업 개선:** 업무 인계·재질문·재입력·누락이 어떻게 달라졌는지 실제 한 건으로 보여준다.
- **확산 가능성:** 공통 부분, 현장별 변경 부분, 적용 주체와 조건을 제시한다. 예상 대상 수만으로 확산 실적을 주장하지 않는다.
- **드물지만 중요한 업무:** 빈도가 낮다고 가치를 배제하지 않는다. 실패의 영향과 실제 통제·검증 사례를 설명하고, 사건 확률·예방 금액을 임의로 만들지 않는다.

금액 환산이 어려우면 관찰 기록·동일 사례 비교·사용자 의견으로 근거를 강화한다. 한 사람의 호평을 전체 조직 효과로 일반화하지 않는다.
